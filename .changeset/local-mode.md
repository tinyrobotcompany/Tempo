Add Local mode: a user-chosen, unencrypted way to open the phone page when HTTPS cannot be used (router DNS filtering, no device identity on a development board, or an expired certificate). It is switched on only by touch on the display, after a confirmation screen that says traffic on the Wi-Fi is not encrypted; no phone, cloud or OTA path can switch it on. While on, port 80 serves the same page and API, the QR shows `http://<address>/`, HTTPS keeps running, and the page shows a permanent "Local mode – not encrypted" banner plus an extra warning on the transport-key form. The display offers it when HTTPS is unavailable or renewal has been overdue for 7 days. Turning it off (on the display, with confirmation) closes port 80 and replaces the pairing code; phones must scan the new QR code. The setting is stored in its own NVS key, survives reboot and OTA, and is off by default (port 80 closed). Validation: host tests for the server, NVS flag, display UI and phone page; device acceptance on real routers is still required.
